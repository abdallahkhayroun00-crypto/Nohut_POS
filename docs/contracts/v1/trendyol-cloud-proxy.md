## Versioned client envelope (proposal for Claude)
All requests have version:1 and action. No extra fields; no arbitrary method/path/headers. x-nohut-agent-token is opaque, never logged. Responses have version:1, status, optional safe result only; Cache-Control:no-store.

- verify: {version:1,action:"verify",commandId,leaseGeneration,envelopeSha256}. A dedicated owner-authorized verification command must be added in backend; do not invent lease. Server performs bounded read-only supplier verification. HTTP 200 {version:1,status:"ok"} only after validating authorized supplier response; 401/403 auth_failed (distinguish client authority denial internally, no tenant hints); supplier_mismatch only if independently proven; 503 unreachable/unknown/publisher_disabled (prefer "proxy_disabled" for this endpoint); 409 conflict/busy. No packages/counts/customer data/raw response/credential values returned. No poll, no order alerts/prints. If provider cannot prove supplier scope, return unknown, not ok.
- poll: {version:1,action:"poll",startMs,endMs,page,size:50}. Authenticated current Windows polling authority and exclusive server-side transport mode cloud; page 0..9, bounded date window, exact ranges agreed with provider docs. 200 {version:1,status:"ok",page,hasNextPage,packages:[...]}, packages are explicit typed minimum fields needed by existing Windows normalizeTgoPackage (contract fixture review required, not arbitrary upstream JSON). No phone/customer direct access. Only advance authoritative checkpoint after all pages saved; overlap, dedupe, no truncation or new-order baseline alerts after restore. Long outages resume in bounded windows, not silent loss.
- execute: {version:1,action:"execute",commandId,leaseGeneration,envelopeSha256}. Validated via atomic `public.nohut_agent_validate_and_read_claim` (tenant + epoch scoped). Derives `platform_action` payload `{action:"accept"|"ready", packageId, preparationMinutes?}` (integer 5..120, default 15) from SQL; preflight GET; single PUT (`/packages/picked` or `/packages/invoiced`); 5xx/timeout returns `unknown` (never blind retry).
- reconcile: {version:1,action:"reconcile",commandId,leaseGeneration,envelopeSha256}. Read-only `GET /packages/{packageId}` for `unknown` outcomes; never mutates.
- store_status_read: {version:1,action:"store_status_read"}. Read-only `GET /stores` returning verified `workingStatus` (`OPEN`|`CLOSED`), `workingHours[]`, `verifiedStoreId`, `verifiedStoreName`.
- store_status_set: {version:1,action:"store_status_set",commandId,leaseGeneration,envelopeSha256}. Validated via `public.nohut_agent_validate_and_read_claim` (`platform_store_status_set` payload `{provider:"trendyol_go", storeId, targetStatus:"OPEN"|"CLOSED", expectedStatus:"OPEN"|"CLOSED", confirmed:true, reason?}`). Verifies `storeId === verifiedStoreId`, preflight `GET /stores`, single `PUT /stores/{storeId}/status`, readback `GET /stores`; 5xx/timeout returns `unknown` (never cancels active orders).

Command IDs UUID, leaseGeneration positive integer, envelopeSha256 exact 64 lowercase hex. No reuse of agent session as lease. Execute results: 200 confirmed (only observed correct upstream status), no_change (only positively proven already satisfied without write), cancelled_before_attempt (only verified abandoned before mutation); 409 conflict/busy/reconciliation_required; 400 invalid_request, 401/403 denied, 405 method_not_allowed, 503 proxy_disabled, unreachable/unknown. Any timeout/5xx/ambiguous response after write attempt is unknown; never label refused or automatically retry/fallback. Durable request and immutable payload digest, per-package fence, intent committed before PUT, attempt consumed once, store provider confirmation and audited reconciliation. No invented provider idempotency support. Treat status reached by another actor separately from evidence of own write.
